# LookHome · 公寓管理系统设计文档

> 版本 v1.0 · 2026-09-12 · 一次设计到位，能力预留，后台可开通
> 参考 UI：寓盟管家（蓝白企业后台风格）

## 1. 产品定位

面向中小型公寓/二房东的私有化部署系统：
- **管理后台（Web）**：房源、房间、租客、合同、账单、抄表、押金、收付款、报表、系统设置
- **租客端微信小程序（预留源码）**：实名注册、绑定房间、查看账单、微信缴费、押金、报修
- **支付双模式**：未配置商户号时走「手工确认收款」；配置后自动切换「微信支付自动入账」

## 2. 核心业务规则（已确认）

| 规则 | 说明 |
|---|---|
| 租金/押金 | 房东**给租客绑定房源时手动设定**（合同创建时填写月租金、押金金额），不以房源档案为准 |
| 费用类型 | 租金、押金、水费、电费、垃圾费（+预留：物业费、网费、燃气费，字典可启停） |
| 垃圾费 | 房间档案配置每月固定金额，生成账单自动带上 |
| 水电费 | 抄表差额 × 单价 × 倍率（支持合租分摊倍率），房租水电分开列示、合并一张账单 |
| 租客注册 | 小程序填写姓名+身份证号+上传证件照 → **默认手工验证**（房东后台通过/驳回），预留自动核验 API |
| 收款确认 | 默认**手工确认**；配置微信支付后自动回调入账 |
| 押金 | 绑定后小程序支付押金；退房时后台发起退押金（预留微信原路退款） |

## 3. 功能清单

### 3.1 管理后台（Web）
- **仪表盘**：今日/本月应收实收、逾期、收缴率、出租率、空置预警、近6月收支趋势
- **房源管理**：项目/楼栋、房间档案（房号/户型/朝向/面积/参考租金/垃圾费/状态[空置/已租/配置/关闭]/可租日）、房间卡片列表
- **租客管理**：注册列表、**身份验证**（待验证/已通过/已驳回，手工审核证件）、租客档案、绑定房间
- **合同管理**：创建合同（选租客+房间+手动填月租金/押金/周期/起止日期）、在租/已退租/到期列表、退房
- **账单管理**：按月生成账单（租金+水电+垃圾费）、抄表录入（集中抄水/电）、未收/已收/逾期、收据打印、延期
- **押金管理**：押金台账（待缴/已缴/已退/部分退）、退押金（全额/部分，记录退款流水）
- **收付款**：收款记录（手工确认/微信自动）、付款记录、**手工确认收款**入口
- **工单**（预留）：报修/保洁
- **报表**：月度收入/支出/利润、年度走势、费用构成（租金/水电/垃圾费分列）
- **系统设置**：站点信息、**小程序配置**、**微信支付配置**、**功能开关**、费用类型字典、管理员

### 3.2 租客端微信小程序（预留源码）
- 微信授权登录、实名注册（身份证+证件照）、查看/绑定房间、账单明细、**微信支付**、缴费记录、押金查看、报修（预留）、订阅消息（缴费成功/收租提醒）

| 配置组 | 配置项 | 未配置时的行为 |

## 5. 数据模型（SQLite，可迁 MySQL）

- `admin_users` 后台账号
- `properties` 项目/楼栋
- `rooms` 房间（含参考租金、垃圾费、状态）
- `tenants` 租客（实名+验证状态：`verify_status`、`id_card_encrypted`、`id_card_photo`）
- `contracts` 合同（绑定记录：`monthly_rent`、`deposit` 手动设定、周期、起止）
- `fee_types` 费用类型字典（租金/押金/水/电/垃圾/物业/网费，启用开关，默认单价）
- `bills` 账单（周期、合计、状态[待缴/已缴/逾期/作废]）
- `bill_items` 账单明细（费用类型、金额、用量、单价）
- `meter_readings` 抄表（水/电、上月/本月读数、用量、金额）
- `payments` 收款（`pay_mode`[manual/wechat]、`confirm_status`、微信交易号、经手人）
- `refunds` 退款（押金退款，原路/手工）
- `work_orders` 工单（预留）
- `settings` KV 配置（站点/小程序/支付/开关）
- `notices` 通知记录（预留）

## 6. 技术栈

- 后端：Node.js 22 + Express + better-sqlite3（DAO 层抽象，可迁 MySQL）
- 管理后台：Vue3 + Vite + Element Plus（蓝白主题，仿寓盟管家布局）
- 小程序：微信原生小程序 + TDesign（预留）
- 支付：微信支付 APIv3（JSAPI），未配置自动降级手工
- 部署：Docker Compose（nginx+node）或宝塔/pm2 手动，SQLite 单文件备份
